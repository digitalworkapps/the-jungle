# The Jungle Throwdown 26

Web app no oficial con los WODs de **The Jungle Throwdown 26**.

- 🐊 **5 WODs** (El Caimán, El Ajolote, La Sanguijuela, La Tarántula, Buey solo bien se lame)
- 🎨 **4 categorías** (Scaled, Intermedio, RX, Master), con una tabla de lo que cambia entre ellas
- 🎥 **Mini-briefings** de la organización resumidos, con el vídeo de cada WOD
- 🧮 **Calculadoras**: puntuación del WOD 1, rope climb y kilos del WOD 3, planificador A/B/C y puntos del WOD 4, reps del WOD 5
- 📱 **PWA**: instalable en el móvil y funciona sin conexión una vez cargada

Enlaces directos: `#inter/3` abre el WOD 3 en Intermedio (`scaled`, `inter`, `rx`, `master` y `1`–`5`).

## Tecnología

HTML + CSS + JavaScript sin dependencias ni build. Todos los datos de los WODs están en `data.js`.
